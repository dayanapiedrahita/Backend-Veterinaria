# Guía de Despliegue en Render

## Requisitos previos
- Cuenta de Render (https://render.com)
- Repositorio Git con este código
- Base de datos PostgreSQL (puedes usar la de Neon que ya tienes)

## Pasos para desplegar

### 1. Preparar el repositorio
- Sube todo el código a GitHub (o GitLab)
- Asegúrate de que el Procfile, render.yaml y requirements.txt estén en el directorio raíz del Backend-Veterinaria

### 2. Crear un Web Service en Render
- Ve a https://dashboard.render.com
- Click en "New +" → "Web Service"
- Conecta tu repositorio de GitHub
- Elige el repositorio y la rama (main/master)

### 3. Configurar el servicio
- **Name**: veterinaria-backend (o el nombre que prefieras)
- **Environment**: Python 3
- **Region**: Elige la más cercana
- **Branch**: main (o tu rama de despliegue)
- **Root Directory**: deja este campo vacío si tu `Procfile`, `render.yaml` y `requirements.txt` están en la raíz del repositorio
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `alembic upgrade head && uvicorn main:app --host 0.0.0.0 --port 8000`

> Si tu aplicación no está en `main`, selecciona el branch correcto en Render (por ejemplo, `feature/backend-login`). También asegúrate de que `Root Directory` quede vacío si los archivos están en la raíz.
>
> Para forzar Python 3.12 en Render, usa un archivo `.python-version` con `3.12` en la raíz del repo o configura `PYTHON_VERSION` con un valor completo como `3.12.12`.

### 4. Configurar variables de entorno
En la sección "Environment Variables" agrega:
```
DATABASE_URL = postgresql://usuario:contraseña@host:puerto/database
ALLOWED_ORIGINS = https://tu-frontend.com,http://localhost:3000
```

**Para obtener DATABASE_URL de Neon:**
- Ve a https://console.neon.tech
- Selecciona tu proyecto
- Copia la connection string en la sección "Connection string"
- Formato: `postgresql+psycopg2://user:password@host:5432/database?sslmode=require&channel_binding=require`

### 5. Deploy
- Click en "Create Web Service"
- Render ejecutará automáticamente:
  1. Install dependencies (`pip install -r requirements.txt`)
  2. Run migrations (`alembic upgrade head`)
  3. Start the app (`uvicorn main:app --host 0.0.0.0 --port 8000`)

## Verificar que funcionó
- Después del despliegue, accede a: `https://tu-app-name.onrender.com`
- Verifica que la API esté lista: `https://tu-app-name.onrender.com/docs`

## Redeploy automático
Render redesplegará automáticamente cuando hagas push a tu rama configurada.

## Troubleshooting
- **Error en migraciones**: Revisa los logs en Render dashboard
- **Error de base de datos**: Verifica que DATABASE_URL sea correcta
- **CORS errors**: Configura ALLOWED_ORIGINS correctamente

## Notas importantes
- El plan FREE de Render pone en sleep el servicio después de 15 minutos sin actividad
- Para producción, considera usar un plan STARTER o superior
- Mantén tu DATABASE_URL segura, no la commites a Git
